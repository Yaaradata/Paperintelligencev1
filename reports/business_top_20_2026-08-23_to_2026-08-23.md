## Audience / list definitions

These lists are **exclusive** among quality-scored papers:

- **Tech** — method/systems papers for builders: application domain is only `general_method` / `scientific_research` (or empty), and audiences include practitioner / technical_leadership / student. Pure `practitioner` alone is **not** used as the tech filter (it matches almost every arXiv CS paper).
- **Business** — decision-maker papers: `enterprise_adoption` in audiences, **or** a concrete sector application (healthcare, finance, cybersecurity, transport, energy, legal, etc.).

Classifier audience labels still matter for provenance; the list split above uses application_domain because `enterprise_adoption` was under-assigned (~2.5%) while sector applications are common (~25%+).
