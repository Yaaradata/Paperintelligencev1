# prompt_version: v001
# stage: adjudication

Resolve competing affiliation and classification evidence into a coherent decision record.

## Rules

1. Prefer higher-precedence affiliation evidence per `policies/affiliation_resolution/v001.yaml`.
2. Unknown / unresolved beats incorrect organisation attribution.
3. Never invent institutions from author names, topic, or writing style.
4. Distinguish `no_evidence_supplied` from `review_required`.
5. Preserve every input evidence row; adjudication appends a new adjudicated result — it does not overwrite.

## Output

Structured JSON recording chosen values, rejected alternatives, and the evidence IDs / sources that justified the choice.
