## One call returns all of

- `audience_relevance` (multi-label from audience list)
- `domain` (single primary domain)
- `subdomains` (zero or more under that domain)
- `application_domain` (multi-label; see mutual-exclusion rule)
- `confidence` (0.0–10.0, 0.5 increments)

## Audience guidance

A paper is relevant if it changes what someone would **do, decide, or believe** — not only if it describes a product.
- A released benchmark with reproducible results can be tech-relevant with no product attached.
- A measured failure in a widely used setting can be product-relevant (someone must decide exposure).
- **Do not require a paper to name an industry, product, or company to be relevant.**

## application_domain / general_method

`general_method` is **mutually exclusive** with every other application domain and is the **correct answer for most papers**, not a fallback.
If you find yourself constructing an argument for why a method "could apply" to a sector, the answer is `general_method`.
